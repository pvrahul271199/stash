# Stash Mobile (React Native / Expo SDK 58)

Native iOS & Android app for **Stash** — *"How much can I spend today?"*

## How to Run on Your iPhone (Easiest Way)

1. If you have an older `expo start` running in your terminal, stop it first by pressing **`Ctrl + C`**.
2. In your terminal, run:
   ```bash
   cd /Users/rahulpv/Downloads/stash/stash-mobile
   npm start
   ```
3. Wait until you see **`Tunnel ready.`** and the QR code in the terminal.
4. Scan the QR code using your **iPhone Camera** app and tap **"Open in Expo Go"**.
